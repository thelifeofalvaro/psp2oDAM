# Programación de Servicios y Procesos — 2º DAM

Repositorio con las prácticas desarrolladas durante la asignatura **Programación de Servicios y Procesos (PSP)** de 2º DAM.

Los ejercicios están orientados al trabajo con procesos, hilos, concurrencia y sincronización en Java.

## 📂 Proyectos

### 📚 Centro de Copias de la Biblioteca

Simulación en Java del funcionamiento de un centro de copias de una biblioteca mediante programación concurrente.

El proyecto plantea un escenario en el que varios estudiantes compiten por utilizar un número limitado de máquinas de copiado, siendo necesario coordinar el acceso al recurso compartido.

**Conceptos principales:**

- Hilos (`Thread` / `Runnable`).
- Exclusión mutua mediante `synchronized`.
- Comunicación entre hilos mediante `wait()` y `notifyAll()`.
- Gestión de recursos compartidos.
- Control temporal de la ejecución.

## 🛠️ Tecnología

- Java
- Programación concurrente
- Hilos y sincronización
